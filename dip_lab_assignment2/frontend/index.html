Linear Contrast Stretch

HSV → stretch V channel to [0,1] → back to RGB. Shows original & stretched luminance histograms conceptually via the V maps.

Histogram Equalization

Global HE on the V channel of HSV. Flattens the cumulative distribution of luminance.

CLAHE

Contrast-Limited Adaptive Histogram Equalization (sliding window on V). Large images are auto-resized for responsiveness.

Histogram Matching

Match the colour distribution of the source to the reference (ignores pure-black background). Useful for retina / medical images.

Manual Threshold

Global threshold T on grayscale. Optionally invert (useful for dark chalk on blackboard).

Otsu Threshold

Automatically chooses T that maximises between-class variance.

Adaptive (Local) Threshold

Per-pixel threshold = local mean − C (integral-image implementation). Handles lighting gradients that defeat global methods.

Image Shrink (Subsampling)

Take every d-th pixel. Larger d produces stronger Moiré patterns.

Image Rotation

Rotate around image centre using bilinear or nearest-neighbour sampling (inverse mapping). Large images are auto-resized.

Canny Edge Detection

Grayscale → Gaussian blur → gradients → NMS → double threshold → hysteresis.

Harris / Shi-Tomasi

Structure tensor → eigenvalues → cornerness → NMS → percentile threshold. Corners marked with visible coloured squares (red = Harris, green = Shi-Tomasi).

Template Matching — NCC

Scene reduced 5×. NCC computed independently for RGB channels.

Unsharp Masking

Blur → mask = original − blur → scale mask → add to original.

Bokeh Effect

Click points around the foreground to form a closed polygon (filled preview). That region stays sharp; background receives circular-disc blur. ≥ 3 points required.
